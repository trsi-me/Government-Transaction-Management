# نظام إدارة ومتابعة المعاملات الرسمية

## فكرة النظام

نظام ويب متكامل لإدارة ومتابعة المعاملات الرسمية والإدارية. يتيح النظام تسجيل المعاملات، متابعتها، تغيير حالتها، ومعرفة تاريخ حركتها. كما يوفر نظام إدارة ديناميكي للقوائم المنسدلة بدون الحاجة لتعديل الكود.

## المميزات الرئيسية

- نظام تسجيل دخول آمن مع جلسات PHP
- إدارة المعاملات (إضافة/تعديل/عرض)
- نظام إدارة ديناميكي للقوائم المنسدلة
- سجل حركة تلقائي لكل معاملة
- نظام بحث وتصفية متقدم
- واجهة مستخدم بسيطة وواضحة
- تصميم متجاوب يعمل على جميع الأجهزة

## متطلبات التشغيل

- خادم ويب يدعم PHP (Apache أو Nginx)
- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث
- متصفح ويب حديث

## طريقة التثبيت

### 1. إعداد قاعدة البيانات

1. افتح MySQL أو phpMyAdmin
2. قم بإنشاء قاعدة بيانات جديدة أو استخدم قاعدة بيانات موجودة
3. قم بتشغيل ملف SQL الموجود في:
   ```
   database/schema.sql
   ```
4. تأكد من تحديث إعدادات الاتصال في:
   ```
   config/database.php
   ```

### 2. إعدادات قاعدة البيانات

افتح ملف `config/database.php` وقم بتعديل الإعدادات التالية:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'tracking_transactions');
```

### 3. إعدادات الخادم

- تأكد من أن المسار الأساسي للنظام يشير إلى المجلد الرئيسي
- تأكد من تفعيل mod_rewrite إذا كنت تستخدم Apache
- تأكد من أن PHP لديه صلاحيات القراءة والكتابة

## استخدام النظام

### تسجيل الدخول

1. افتح المتصفح وانتقل إلى `login.php`
2. أدخل اسم المستخدم وكلمة المرور
3. اضغط على "تسجيل الدخول"

### إضافة معاملة جديدة

1. من القائمة الرئيسية، اختر "إضافة معاملة"
2. املأ بيانات المعاملة
3. اختر الحالة والجهة والأولوية من القوائم المنسدلة
4. اضغط على "حفظ"

### إدارة القوائم المنسدلة (للمدير فقط)

1. من القائمة الرئيسية، اختر "إدارة القوائم"
2. يمكنك إضافة أنواع قوائم جديدة
3. يمكنك إضافة عناصر لكل نوع قائمة
4. يمكنك تعديل أو حذف العناصر الموجودة

### البحث والتصفية

1. من صفحة "قائمة المعاملات"
2. استخدم حقول البحث والتصفية
3. يمكنك البحث برقم المعاملة أو العنوان
4. يمكنك التصفية حسب الحالة، الجهة، أو التاريخ

### عرض تفاصيل المعاملة

1. من قائمة المعاملات، اضغط على "عرض"
2. ستظهر جميع تفاصيل المعاملة
3. يمكنك رؤية سجل حركة المعاملة في الأسفل

## الصلاحيات

- **مستخدم عادي:** يمكنه إضافة وتعديل وعرض المعاملات
- **مدير:** جميع صلاحيات المستخدم العادي بالإضافة إلى:
  - إدارة القوائم المنسدلة
  - إدارة المستخدمين

## ملاحظات مهمة

- جميع القوائم المنسدلة قابلة للإدارة من لوحة التحكم بدون تعديل الكود
- يتم تسجيل جميع التغييرات تلقائياً في سجل الحركة
- لا يمكن حذف سجلات الحركة
- رقم المعاملة يتم إنشاؤه تلقائياً عند الإضافة

## الدعم الفني

في حالة وجود أي مشاكل:

1. تأكد من إعدادات قاعدة البيانات
2. تأكد من صلاحيات الملفات والمجلدات
3. راجع ملفات السجلات في الخادم
4. تأكد من أن جميع الملفات موجودة في المسار الصحيح
